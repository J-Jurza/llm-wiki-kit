# Inbox

Everything that should end up in the wiki lands here first. Drop a file, clip a web page (the Web Clipper is set to `Inbox/Clippings/`), paste a note. Name files so the agent can tell what they are: `article - how to do great work.md`, `book notes - deep work.md`, `transcript - huberman sleep toolkit.md`.

Then open Claude on the vault and say "process my inbox", or paste `P2 - First Ingest` the first time.

What belongs here: articles, book notes, transcripts, course notes, your own written-up thinking on a topic. What does not: to-do lists, itineraries, contracts, journal entries, anything from `Private/` you have not deliberately copied over.

Processed files move to `Archive/`. This folder should be empty most of the time.
