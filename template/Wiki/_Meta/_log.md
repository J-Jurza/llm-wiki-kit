# Wiki Log

Append-only record of everything done to the wiki: ingests, syntheses, lint runs, queries that were filed, structural changes. Newest at the top. Every agent session that changes the wiki ends with one entry here.

Format:

```
## YYYY-MM-DD type | short title

**What:** one or two sentences.
**Decisions:** non-obvious choices and why. "None" is valid.
```

Types: `ingest`, `synthesis`, `lint`, `query`, `structure`.
