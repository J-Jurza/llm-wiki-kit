LLM Wiki Kit, version 0.2.0

Set up your AI-maintained wiki

A knowledge base that Claude writes and you read in Obsidian. About 45 minutes of installing, then 30 minutes of talking to it. You will not write code.

Works on macOS 13 or later and Windows 10 (1809) or later.

Seven steps

  1. 1

    Get the kit 2 min

    Unzip the file you were sent. Or in GitHub Desktop choose File, Clone repository, and paste the link.

    Check: you can see folders named template, prompts and docs.
  2. 2

    Install Obsidian and create a vault 5 min

    Open Obsidian, choose Create new vault, name it, put it in Documents, click Create. Then quit Obsidian.

    Check: an empty folder with your vault's name exists in Documents.
  3. 3

    Install Git 5 min

    Mac: open Terminal (search for it with Spotlight), type git --version, press Return, and accept the offer to install developer tools. Windows: run the Git installer with the defaults.

    Check: git --version prints a version number.
  4. 4

    Copy the template into your vault 3 min

    Show hidden files first. Mac: press Cmd Shift . in Finder. Windows: View, Show, Hidden items. Open the kit's template folder, select everything inside it including the hidden .claude folder, copy, and paste into your vault folder.

    Check: open Obsidian. You see Inbox, Archive, Private, Profile and Wiki. The .claude folder is hidden there, which is correct.
  5. 5

    Install VS Code and Claude Code 10 min

    Install VS Code. Open it, choose File, Open Folder, pick your vault, and say yes to trusting the folder. Press Cmd Shift X (Mac) or Ctrl Shift X (Windows), search Claude Code, click Install. Open the Claude panel from the left bar, click Sign in, and finish in the browser.

    Check: type /skills in the Claude panel. You see wiki-ingest, wiki-synthesise, wiki-lint, wiki-query and wr-unslop. If not, the hidden folder in step 4 did not copy.
  6. 6

    Install the Web Clipper 3 min

    Add the extension to your browser. In its settings choose your vault and set the note location to Inbox/Clippings. Clip any article as a test.

    Check: the clipped page appears in Inbox/Clippings in Obsidian within a few seconds.
  7. 7

    Run the first two prompts 20 min

    Open prompts/P0 - Bootstrap.md from the kit, copy the block under "Paste this", and paste it into the Claude panel. It checks the setup, asks your name and makes the first commit. Then do the same with P1 - Setup Interview.md and answer its questions. It writes your profile and names your first topic areas.

    Check: Profile/About Me.md is filled in and the health check reported zero errors.

You are set up. Put three things in Inbox (a clipped article, your notes on a book, a transcript) and paste P2 - First Ingest.md. Read what Claude wrote with the source open beside it.

From then on

WhenDo
Any timeClip an article, or drop a file or a note into Inbox
Weekly, 20 minutesPaste P6 - Weekly Routine.md. Claude processes the inbox, says what is ready to write up, and suggests one question
When you have a questionPaste P5 - Ask the Wiki.md with your question. Keep the good answers as pages
MonthlyPaste P4 - Health Check.md. Pick two or three fixes from the report

Three rules

  • Sources go in the inbox, nowhere else. Dropping a file straight into Wiki skips the step that makes it findable.
  • Anything you do not want Claude to read goes in Private. To have something from there analysed, copy it to the inbox first and move the original back after.
  • Read what Claude writes for the first few weeks. It is good and it is not perfect. Your corrections teach it, and you learn what to trust.

If something goes wrong

SymptomFix
Claude says it cannot find the skillsThe hidden .claude folder did not copy. Show hidden files, copy it, start a new session
Clipped pages land in the wrong folderClipper settings: note location Inbox/Clippings
A link in Obsidian goes nowherePaste the health check prompt. Broken links are its first finding
Claude asks permission for a commandNormal for anything outside the pre-approved list. Say yes to what you understand
Things get slow or confusedStart a new chat. The index and log are the memory, not the conversation

The full list is in docs/03 - Troubleshooting.md. When asking for help, paste the last entry from Wiki/_Meta/_log.md.
