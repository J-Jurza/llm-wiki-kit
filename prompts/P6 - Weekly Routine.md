# P6: Weekly routine

**When:** once a week, twenty minutes. The one prompt that keeps the wiki alive.

## Paste this

```
Weekly wiki routine. Do these in order and keep the reports short.

1. Process Inbox/ and Inbox/Clippings/ with the wiki-ingest skill. List what you wrote and what you skipped.

2. Tell me whether any concept is now covered by three or more source pages and has no Knowledge page. If yes, name it and ask whether to synthesise it now.

3. Look at Wiki/3. Living/. Is any plan or protocol older than three months on a topic that has had new sources since? Name it.

4. Suggest one question my wiki could answer well this week, based on what is in it.

5. If anything changed, append one log entry and commit if git is on.
```

Then answer the two questions it asks you: synthesise or not, and whether to ask the suggested question. Done.

## Monthly, add

```
Also run the wiki-lint skill and give me the numbered findings.
```
